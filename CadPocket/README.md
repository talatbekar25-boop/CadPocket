# CadPocket

Basit Android DXF görüntüleyici MVP.

## Özellikler
- Telefonda DXF dosyası seçme
- ASCII DXF içindeki LINE, CIRCLE, ARC ve LWPOLYLINE nesnelerini çizme
- İki parmakla yakınlaştırma/uzaklaştırma
- Tek parmakla sürükleme
- "Sığdır" ve çift dokunma ile çizimi ekrana sığdırma

## Android Studio ile çalıştırma
1. Android Studio açın.
2. Open seçin ve bu klasörü açın.
3. Gradle senkronizasyonunun bitmesini bekleyin.
4. USB hata ayıklama açık bir Android telefon bağlayın veya emülatör açın.
5. Run düğmesine basın.

## Not
Bu ilk sürüm DWG açmaz. DWG desteği için ayrı bir SDK/dönüştürme katmanı gerekir.
